# 焚信

一个使用 Next.js 开发的阅后即焚文本工具，只支持文本字符，不使用数据库，适合快速部署到 Vercel。

## 方案说明

- 文本在浏览器端使用 Web Crypto API 加密。
- 加密后的密文存放在 URL hash 中，hash 不会发送到服务器。
- 阅读页会在解密后立即清除地址栏中的 hash，并在当前浏览器会话内标记为已读。
- 不依赖数据库、对象存储或第三方后端服务。

这意味着它非常轻量、部署简单，但“阅后即焚”是基于前端链接消费体验实现的，不是依赖服务端状态的强一致单次读取。

## 本地开发

```bash
npm install
npm run dev
```

## 部署到 Vercel

1. 将项目推送到 Git 仓库。
2. 在 Vercel 中导入该仓库。
3. Framework Preset 选择 Next.js。
4. 无需额外环境变量，直接部署即可。

## 使用限制

- 建议文本不超过 4000 个字符，否则链接可能过长。
- 仅支持现代浏览器，因为依赖 `Web Crypto API`。
